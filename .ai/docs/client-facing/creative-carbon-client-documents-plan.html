This plan compares each one with what the app prints now and lists the work to match them field for field. It also covers importing the die chart and the rod and tube lists. Nothing is built yet. Phases

Same way of working as before: finish a phase, test it plus everything before it, tick it here, commit, then start the next. Every print gets a side-by-side check against the client's paper before it is ticked.

Questions for the client before we start

  1. Please send the logo, the ISO / TÜV / IAF badges, the directors' signatures and the round stamp as image files (PNG, transparent background if possible).
  2. e-Invoice: is the IRN generated in Tally today? If so, we read the IRN, Ack and QR back from Tally; if not, we need their GSP / IRP login to generate it ourselves.
  3. In the quotation no. CCPL/2025-2026/MS/091, what does MS stand for: a salesperson's initials or a department? Does each person have their own counter?
  4. The quotation prints "CCPL" while the PO and TC print "CCCPL". Keep both as they are?
  5. Last numbers used this year for quotation, proforma, invoice, purchase order and TC, so our series carries on from them.
  6. The excise registration no. on the quotation is no longer used under GST. Keep printing it?
  7. The die chart has blanks ("……") and repeated codes (e.g. "85-A" twice with different sizes). Is each row a separate die?
  8. The test-certificate values per grade: is there one approved IS 2036 sheet per grade we can load as the templates?
